US-02 · US-03 · US-04 — Sprint 1

Gestión de la Calidad del Software

Explora los estándares internacionales, las técnicas de aseguramiento y las herramientas utilizadas por equipos QA profesionales.

Fundamentos de Calidad

Conceptos clave: definición de calidad, control vs. aseguramiento y estándares ISO.

Definición

¿Qué es la Calidad de Software?

El grado en que un sistema satisface los requisitos especificados, las necesidades del usuario y las expectativas implícitas del cliente.

Control

Control de Calidad (QC)

Proceso reactivo: verifica que el producto terminado cumple los estándares. Incluye inspección, pruebas y revisión de código.

Aseguramiento

Aseguramiento de Calidad (QA)

Proceso proactivo: define y mejora los procesos de desarrollo para prevenir defectos antes de que ocurran.

Diferencia clave

QC vs. QA

QC se enfoca en el producto (¿es correcto?). QA se enfoca en el proceso (¿estamos trabajando bien?). Ambos son complementarios.

ISO 9126

Funcionalidad

El software hace lo que el usuario necesita: adecuación, exactitud, interoperabilidad, seguridad y conformidad.

ISO 9126

Confiabilidad

Capacidad de mantener el nivel de desempeño bajo condiciones establecidas: madurez, tolerancia a fallos y recuperabilidad.

ISO 9126

Usabilidad

Esfuerzo requerido para usar el sistema: comprensibilidad, facilidad de aprendizaje, operabilidad y atractivo.

ISO 9126

Eficiencia

Relación entre el nivel de desempeño y los recursos usados: comportamiento temporal y utilización de recursos.

ISO 9126

Mantenibilidad

Facilidad de modificación: analizabilidad, cambiabilidad, estabilidad y testabilidad.

ISO 9126

Portabilidad

Capacidad de ser transferido a otro entorno: adaptabilidad, instalabilidad, coexistencia y reemplazabilidad.

SQuaRE

¿Qué es ISO/IEC 25000?

Software Quality Requirements and Evaluation. Evolución de ISO 9126 que proporciona un marco unificado para la evaluación y requisitos de calidad.

División 2501n

Modelo de Calidad

Define características: adecuación funcional, eficiencia de desempeño, compatibilidad, usabilidad, confiabilidad, seguridad, mantenibilidad y portabilidad.

División 2502n

Medición de Calidad

Métricas internas (código fuente), externas (comportamiento del sistema) y en uso (satisfacción del usuario en contexto real).

División 2504n

Evaluación de Calidad

Proceso de 5 pasos: definir requisitos → especificar evaluación → diseñar evaluación → ejecutar → concluir con evidencia objetiva.

Densidad

Densidad de Defectos

Defectos encontrados / KLOC (1000 líneas de código). Indica la concentración de bugs en el código base.

Cobertura

Cobertura de Pruebas

% de código ejecutado por las pruebas automatizadas. Una cobertura alta (>80%) reduce el riesgo de regresiones.

MTBF

Tiempo Medio entre Fallos

Promedio de tiempo que el sistema opera sin fallos. Un MTBF alto indica alta confiabilidad del sistema.

Complejidad

Complejidad Ciclomática

Número de caminos linealmente independientes en el código. Valores >10 indican código difícil de testear y mantener.

Técnicas de Aseguramiento de la Calidad

Haz clic en cada tarjeta para ver la descripción detallada de cada técnica.

Toca una tarjeta para girarla

Caja Negra

Prueba funcional

Caja Negra

Prueba el comportamiento externo del sistema sin conocer la estructura interna. Se basa en entradas y salidas esperadas.

Caja Blanca

Prueba estructural

Caja Blanca

Prueba la estructura interna del código. El tester conoce el código fuente y diseña casos para cubrir todos los caminos lógicos.

Prueba Unitaria

Nivel de componente

Prueba Unitaria

Verifica el funcionamiento de unidades individuales de código (funciones, métodos, clases) de forma aislada. Usa mocks para dependencias.

Integración

Nivel de módulos

Prueba de Integración

Verifica la interacción entre módulos o componentes. Detecta problemas de interfaces, comunicación e intercambio de datos.

Sistema

Nivel de sistema completo

Prueba de Sistema

Evalúa el sistema completo e integrado para verificar que cumple los requisitos especificados, en un ambiente similar al de producción.

Aceptación (UAT)

Nivel de usuario final

Prueba de Aceptación

Valida que el sistema cumple los criterios de aceptación del cliente. Es la última barrera antes de desplegar a producción.

Estática

Sin ejecución de código

Prueba Estática

Analiza el código o documentos sin ejecutarlos. Incluye revisiones de código, inspecciones, walkthroughs y análisis de linters.

Dinámica

Con ejecución de código

Prueba Dinámica

Ejecuta el programa con entradas de prueba y observa el comportamiento. Engloba todas las pruebas de caja negra y blanca en tiempo real.

Herramientas de Aseguramiento

Filtra por categoría para explorar las herramientas más usadas por equipos QA profesionales.

Jira
Bug Tracker

Plataforma de gestión de proyectos ágiles con seguimiento de incidencias, sprints y tableros Kanban.

Bugzilla
Bug Tracker

Sistema de seguimiento de bugs open-source. Estándar en proyectos de código abierto con potente búsqueda de defectos.

GitHub Issues
Bug Tracker

Sistema integrado de seguimiento en GitHub. Ideal para vincular issues directamente con commits y pull requests.

ESLint
Linter

Analizador estático para JavaScript/TypeScript. Detecta errores de estilo y posibles bugs sin ejecutar el código.

SonarQube
Linter

Plataforma de análisis estático multi-lenguaje. Detecta vulnerabilidades, code smells y calcula deuda técnica.

Pylint
Linter

Analizador de código Python que verifica errores, aplica convenciones PEP8 y detecta código duplicado o problemático.

TestRail
Gestión de Pruebas

Plataforma de gestión de casos de prueba. Centraliza planificación, ejecución y reporte de resultados de testing.

Zephyr
Gestión de Pruebas

Plugin de gestión de pruebas para Jira. Permite crear, organizar y ejecutar casos de prueba directamente en el ecosistema de Jira.

Cypress
Automatización

Framework de pruebas E2E para aplicaciones web. Ejecución en tiempo real en el navegador con debugging visual integrado.

Playwright
Automatización

Framework de Microsoft para pruebas cross-browser. Soporta Chromium, Firefox y WebKit con una sola API.

Selenium
Automatización

Estándar histórico en automatización web. Soporta múltiples lenguajes (Java, Python, JS) y todos los navegadores principales.

Jest
Automatización

Framework de pruebas unitarias de JavaScript/TypeScript. Zero-config, snapshot testing y cobertura de código integrada.
