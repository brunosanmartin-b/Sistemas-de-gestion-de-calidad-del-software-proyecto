# Índice Maestro de Documentos de Referencia — Proyecto SGCS 2026 (VELORA)

Este índice organiza los **8 documentos de referencia** del proyecto (los 7 archivos maestros en `../archives zebolla/` más el documento oficial de pruebas y planificación en `documentacion/`) para que cualquier agente o miembro del equipo pueda localizar la información exacta con el **menor consumo de contexto posible**.

> [!TIP]
> **Instrucción de Uso:** Consultá primero la tabla de abajo para elegir **únicamente** el resumen Markdown de `documentacion/referencias/` pertinente a tu tarea actual. Acudí al archivo original solo cuando necesites verificar citas literales, diagramas visuales o páginas específicas.
